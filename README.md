# rename

Windows向けの連番リネームアプリ。
ファイルを並べて、連番のファイル名へまとめて変更できます。

## 使い方

1. ファイルやフォルダをドロップするか、「親フォルダから追加」で子フォルダ内のファイルを読み込む。
2. 順序、連番形式、開始番号、出力先を設定する。
3. 変更後の名前を確認し、「リネーム実行」を押す。

親フォルダからの追加では、子フォルダ名・ファイル名の自然順で通し番号を付け、指定した出力先へまとめます。
実行すると、元ファイルをリネーム・移動します。
クリア時の動作は「設定」から変更できます。

## 開発

Go、Wails、React、TypeScriptで実装しています。
ビルド方法は [ビルドガイド](build/README.md) を参照してください。
